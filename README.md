# Landing Page
Uma **Landing Page** moderna e responsiva desenvolvida para demonstrar habilidades fundamentais em *front-end development*. O projeto foca na experiência do usuário e na clareza visual.
## Destaques do Projeto

- Estrutura semântica com HTML5.
- Estilização avançada com CSS3 puro.
- Design totalmente responsivo (Mobile First).
- Otimização de carregamento e performance visual.

## Tecnologias Utilizadas
| Tecnologia | Aplicação |
| --- | --- |
| HTML5 | Estruturação e semântica do conteúdo |
| CSS3 | Layout (Flexbox/Grid) e estilização |[1]
## Como Visualizar
Para ver o projeto em seu navegador, basta clonar o repositório e abrir o arquivo principal:
`open index.html`
